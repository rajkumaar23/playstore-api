      Reference
      
Two shapes. That's the whole API.

      
No auth, no rate-limit headers to juggle. Just GET.

    

    

      

        

          
GET/json

          
Everything, in one call. id is the package ID; gl is an optional two-letter country.

        

        
curl "https://play.rajkumaar.co.in/json?id=com.dd.doordash&gl=US"

      

      

        

          
GET/<field>

          
A single field in shields.io format — {"label": …, "message": …}. Built for badges, handy for scripts.

        

        
curl "https://play.rajkumaar.co.in/downloads?id=com.dd.doordash"
# → {"schemaVersion":1,"label":"Downloads","message":"50,000,000+"}

      

      

        

          
GET/<field> → shields

          
Point shields.io's endpoint at any field and drop the markdown in your README.

        

        
![Downloads](https://img.shields.io/endpoint?color=success&url=https://play.rajkumaar.co.in/downloads?id=com.dd.doordash)

      

    

    

      
      
A note on ratings. Play Store ratings are region-specific, so rating and noOfUsersRated can come back as 0 for the default region. Pass &gl=IN (or any ISO country code) to get localised values. Package IDs accept [A-Za-z0-9._-], max 200 characters.
